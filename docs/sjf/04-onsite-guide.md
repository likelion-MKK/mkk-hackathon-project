# 현장 운영 가이드

## 장소

- 코엑스 마곡 1층 전시장
- 서울 강서구 마곡중앙로 143
- 대중교통 이용 권장
- 교통비와 주차비는 지원되지 않음

## 입장

- 입장 가능 시간: 10:00~12:00
- 개회식은 12:00 정각 시작이므로 11:30까지 입장 완료 권장
- 커뮤니티 플랫폼에 제출한 명단을 기준으로 전자출입증 알림톡이 발송됩니다.
- 전자출입증 QR을 입구 키오스크에 태그하면 명찰이 출력됩니다.
- 출력된 명찰, 목걸이, 케이스를 챙겨 입장합니다.

## 행사 중 출입

- 행사 시간 12:00~19:00에는 출입이 제한됩니다.
- 입장 시간 10:00~12:00에는 자유롭게 출입할 수 있습니다.
- 흡연 구역 방문은 10분 외출이 허용되며 출구 명단에 외출·복귀를 기록해야 합니다.
- 복귀 시간 미준수 경고 3회 누적 또는 허용 구역 이탈 적발 시 해당 학교 전원이 수료하지 못할 수 있습니다.
- 행사 시작 후 식사를 위해 외부로 나갈 수 없으므로 운영진의 식사 안내를 따릅니다.

## 부스 운영

| 항목 | 내용 |
| --- | --- |
| 설치 | 10:00~12:00 |
| 운영 | 12:40~18:00 |
| 배정 | 학교당 1개 부스, 팀별 교대 운영 |
| 기본 제공 | 1500×760×740mm 테이블과 검정 커버, 의자 4개, 2구 멀티탭 1개 |
| 팀 준비 | 노트북, 모니터, 충전기, 변환 젠더, 오프라인 자료 |
| 패널 | 1m × 2.5m 패널 3개 안내 |
| 비용 | 부스 장식 비용 별도 지원 없음 |

부스는 결과물 전시와 네트워킹 공간입니다. 빈 시간이 길지 않도록 학교 안에서 운영 시간을 나누고, 팀별 담당자를 미리 정하세요.

## 네트워크 장애 대비

현장 네트워크가 느릴 수 있다고 안내되어 있습니다.

- IR Deck PDF를 로컬에 저장
- 100초 데모 영상과 핵심 화면 녹화본을 로컬에 저장
- 배포 URL과 테스트 계정 확인
- 네트워크 없이도 설명할 수 있는 스크린샷 준비
- 모바일 핫스팟 가능 여부와 데이터 용량 확인
- 라이브 데모 실패 시 보여 줄 짧은 복구 동선 연습

## 현장 투표 날짜 충돌

공식 메인 가이드의 D-day 표시에는 투표 종료가 **8월 27일**로 보이지만, 부스 운영 가이드에는 플랫폼 투표 기간이 **8월 21일 10:00~8월 28일 23:59**로 적혀 있습니다. 날짜가 서로 다르므로 운영진 공지와 최신 페이지를 확인한 뒤 팀 일정에 반영하세요.
