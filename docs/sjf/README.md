## 지금 먼저 확인할 것

- 참가 신청 마감은 **8월 6일**로 안내되어 있습니다.
- 멘토링 운영 기간은 **7월 23일~8월 20일**입니다.
- 최종 제출 마감은 **8월 21일 09:59:59**입니다.
- 프론트엔드·백엔드 GitHub 저장소는 **Public**이어야 하며 팀당 최대 3개까지 제출할 수 있습니다.
- 평가 대상 브랜치는 `main` 또는 `master`이며, 제출한 코드와 배포 결과가 일치해야 합니다.
- 제출 마감 후 저장소를 수정하면 즉시 탈락할 수 있으므로 제출 직전에 커밋과 배포 상태를 동결해야 합니다.
- AI는 아이디어 설명에만 머물면 안 됩니다. 실제 사용자 흐름 안에서 작동해야 합니다.

## 출처 해석 원칙

- MCM 고객 비중, 해외 매출 비중 등은 **SJF Q&A에 적힌 파트너 설명**으로 기록했으며 별도로 검증한 기업 공시 수치가 아닙니다.
- 고객 원본 데이터는 제공되지 않습니다. 더미 데이터 사용은 가능하지만, 더미 데이터로 시연하는 기능과 AI 흐름 자체는 실제로 작동해야 합니다.
- 산돌구름의 외부 공유 금지 혜택 링크처럼 공개 저장소에 올리면 안 되는 정보는 링크를 복제하지 않았습니다.
- 공식 페이지 사이에 날짜가 다른 항목은 임의로 하나를 확정하지 않고 충돌 사실을 표시했습니다.
