## 멘토링

- 운영 기간: 7월 23일~8월 20일
- 멘토는 방향과 피드백을 제공하며 직접 개발하거나 코드를 수정할 수 없습니다.
- 질문 채널 글은 팀장만 작성합니다.
- 질문 제목 형식: `[질문] 팀명 - 키워드`
- 공개·비공개 질문이 가능하며 관련 기존 글이 있다면 링크합니다.
- 답변 완료 후 추가 질문은 새 글로 작성합니다.
- 멘토를 지정해서 질문할 수는 없지만, 필요하면 운영진이 1:1 세션을 제안할 수 있습니다.
- 1:1 온라인 세션은 팀당 최대 3회, 한 팀과 한 멘토 구성으로 안내되어 있습니다.
- 세션 신청 제목 형식: `[세션] 팀명 - 멘토명, 희망 일정`

## OpenAI API Credit

- 팀원 전원이 OpenAI Platform에 가입합니다.
- 팀장이 프로젝트를 만들고 팀원을 초대합니다.
- 신청에는 Project ID가 아니라 **Organization ID**를 사용합니다.
- 한 팀당 Organization ID 하나를 제출합니다.
- 원문 일정: 신청 약 7월 28일 자정, Organization ID 제출 7월 29일 17:00, 지급 7월 31일, 12월까지 사용.

참고: [OpenAI 개발자 문서](https://developers.openai.com/) · [Organization ID 확인](https://platform.openai.com/orgid)
